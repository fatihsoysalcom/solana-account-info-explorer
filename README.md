# Solana Account Info Explorer

This example Python script demonstrates how to query Solana on-chain account data using only standard library modules. It connects to a Solana RPC endpoint, fetches information for a specified public key, and displays its balance, owner, and other properties. This simulates a basic 'account explorer' functionality.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
